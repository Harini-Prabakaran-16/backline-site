# Backline website

Single-page marketing site for Backline: renewal and policy admin for insurance brokers.

Live at **https://backline.avanext.ai**

- `index.html` is the whole site (inline CSS and JS, no build step).
- Hosted on GitHub Pages from the `main` branch. `CNAME` holds the custom domain.
- DNS: a `CNAME` record `backline` → `harini-prabakaran-16.github.io` on avanext.ai (Crazy Domains).

## Deploying

Push to `main`. GitHub Pages republishes in about a minute.
